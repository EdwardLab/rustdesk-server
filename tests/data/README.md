# GeoIP test fixture

`GeoIP2-City-Test.mmdb` is synthetic test data from
[MaxMind-DB](https://github.com/maxmind/MaxMind-DB/blob/main/test-data/GeoIP2-City-Test.mmdb).
It is distributed under Apache-2.0; see `LICENSE-APACHE` in this directory.
It is only used by tests. It is not a real geolocation database and must not
be used for production routing.
